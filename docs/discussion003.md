## 三、研究过程的问题和不足（按严重程度排序）

### 3.1 【致命】"信号衰减"的结论是regime混淆，不是衰减

我把 P&L 按当日 open→close 幅度分组：

**每类日子的单日收益（bp of AUM）：**

| 日子类型 | PRE 频率 | PRE 收益 | POST 频率 | POST 收益 |
|---|---:|---:|---:|---:|
| \|io\| > 2% | 4.85% | +126.5 bp | **1.64%** | **+257.0 bp** |
| 1% < \|io\| ≤ 2% | 14.15% | +74.2 bp | 10.77% | +82.5 bp |
| \|io\| ≤ 1%（安静日） | 81.00% | −10.5 bp | 87.59% | −12.6 bp |

**条件收益没有衰减，反而变强了。变的是 regime 构成：大幅日频率从 4.85% 掉到 1.64%，掉了三分之二。**

反事实测算：用 post 期自己的条件收益、配上 pre 期的日子类型分布，年化是 **+35%**，不是 5%。

你的 `decision_rule`（post gross edge per traded share 是否 > 0）是**无条件**度量，直接被 regime mix 污染。同一个信号，在少了三分之二 payoff 日的窗口里跑，per-share edge 必然下降，这和信号质量无关。

我不是说一定没衰减——post 只有 9 个大幅日，257bp 里 2025-10-10 一天就占了大半。**正确的表述是：post 期几乎不含任何关于信号衰减的统计信息。** 你既不能说它衰减了，也不能说它没衰减。README 现在的措辞是过度推断。

### 3.2 【致命】这是一个 long straddle，不是 alpha

按 SPY 日内 open→close 十分位分组的 gross P&L（全样本）：

| decile | 平均 io | gross P&L | 占总额 |
|---|---:|---:|---:|
| D0 | −2.0% | +$2,525,553 | **+162%** |
| D1–D7 | ~0% | −$2,938,515 | **−190%** |
| D8 | +1.0% | +$539,120 | +35% |
| D9 | +2.0% | +$1,427,825 | +92% |

标准的 long straddle 形状：**在 70–80% 的日子里付 theta，在尾部收钱。**

- 全样本 66% 的 gross P&L 来自 SPY 日内跌超 2% 的 120 天（占样本 2.6%）
- Post 期：6 天贡献了 post gross 的 **234%**
- 剔除 post 期最好的 1 天，post 净 P&L 变成 **−$51,512**；剔除前 3 天，**−$211,038**
- Post hit rate（gross>0）仅 26.6%，中位数日 P&L = $0

这直接推翻你现在的三个报告口径：

1. **Sharpe 是错的度量。** skew 3.11、kurtosis 26.2，Sharpe 的分布本身就不稳定，而且系统性低估凸性结构的价值。
2. **SPY total return 是错的 benchmark。** 正确的比较对象是"买同等凸性要花多少钱"——rolling put spread、VIX call、或者直接 long straddle 的 theta。你的安静日 bleed 稳定在 −10 到 −13 bp/day，这就是隐含的权利金支出，可以直接和挂牌期权的 theta 比价。
3. **组合价值被 standalone 口径完全抹掉了。** 我做了一个简单叠加（SPY + w × 策略，同一笔本金）：

| w | CAGR | vol | Sharpe | MDD |
|---:|---:|---:|---:|---:|
| 0（纯 SPY） | 9.72% | 19.87% | 0.57 | **−52.81%** |
| 0.50 | 18.48% | 20.55% | 0.93 | −41.91% |
| 1.00 | 27.28% | 23.49% | 1.14 | **−35.77%** |

**收益和回撤同时改善**，因为月度相关性 −0.25（post −0.42），且在你自己列的 SPY 最差 10 个季度里策略全部为正。你现在的 headline 表格（"post 跑输 SPY 14.22pp"）把这个策略最有价值的属性完全隐藏了。

### 3.3 【严重】成本模型漏了 SEC Section 31 费，量级大于全部现有成本

引擎的成本项只有 `comm_per_share` / `min_comm` / `slip_per_share` + 融资。缺了监管费。

SEC 于 2026 年 2 月 27 日公告，自 2026 年 4 月 4 日起，Section 31 费率设为每百万美元 20.60 美元，仅对**卖出**征收。而且这个费率历史上极不稳定——2025 年 5 月 14 日起从每百万 27.80 美元临时降至 0.00，2026 年 4 月 4 日起改为 20.60。

按 post 期实际成交量和均价 $622 算：

```
SEC fee ≈ 0.643¢ / traded share
现模型成本  0.600¢  →  含 SEC fee  1.243¢
post gross edge     2.092¢
post net edge  1.492¢  →  0.850¢   (−43%)
```

**这一项比你整个 commission + slippage 假设还大。** 而且它必须像你的 financing rates 一样做成 PIT 序列，不能用常数——费率在样本期内变动过很多次，包括归零期。（FINRA TAF 每股 $0.000166 可忽略。）

含 SEC fee 后 post 的**盈亏平衡滑点是 $0.0110/share**，即价格的 0.18 bp。

### 3.4 【严重】成本是状态无关的，但 P&L 是状态集中的

固定 $0.0025/share 滑点同时用在：

| | 分钟级 high-low 中位数 |
|---|---:|
| Post 期典型日 | 3.4 bp |
| Post 期 P&L 前 10 日 | 4.9 bp（1.4x） |
| 2025-04-09 | **24.0 bp**（90 分位 50.1 bp） |
| 2025-04-04 | 17.9 bp |

**你的成本模型在恰好产生全部 P&L 的那些日子里错得最厉害。** 这些日子 spread 是平时的 5–10 倍、深度崩塌、LULD 熔断、reopening auction。而 break-even 滑点只有 $0.011/share。

所以你 roadmap 里排第一的"market impact 与容量"**方向对但 scope 错了**：在 $100k AUM、SPY 这个标的上，participation rate / ADV 冲击是不存在的问题（SPY 日成交额 $300–800 亿）。真正要建模的是 **state-dependent spread**——把滑点写成实时波动率和 spread 的函数，然后专门在那 10 天上校准。这是完全不同的工作。

### 3.5 【中等】4x cap 与低波动 regime 的不良交互

按滞后 dvol 五分位（全样本，bp of AUM per day）：

| 分位 | 平均杠杆 | gross | cost | cost/gross |
|---|---:|---:|---:|---:|
| q0（最低波动） | 3.98 | 6.82 | 2.01 | **29.5%** |
| q1 | 3.23 | 9.68 | 1.45 | 15.0% |
| q3 | 1.78 | 7.81 | 0.88 | 11.2% |
| q4（最高波动） | 1.07 | 6.22 | 0.69 | 11.0% |

vol targeting 把 gross 拉平得不错（6–10 bp 之间），**但成本没有被 vol-scale**：最低波动分位烧掉 29.5% 的毛边际，是最高分位的 2.7 倍。2017 年 76% 的日子顶在 4x cap，全年 −10%。

这不致命，但结构上是错的：per-share 成本固定、edge 随波动缩放，低波动 regime 的成本/收益比必然恶化。

### 3.6 【中等】统计推断被"明确延期"，但它恰恰是唯一的约束项

你在 spec 里写"点估计；HAC 与 block bootstrap 明确延期"。问题是你的 headline claim（pre 1.18 vs post 0.30）本质就是两个点估计的比较。

我跑了 20 日 block bootstrap（5000 次）：

```
post Sharpe 点估计 0.28
90% 区间 [−0.58, +1.39]
P(Sharpe < 0) = 23.3%
```

**post 的 Sharpe 与 0 无法区分，与 pre 的 1.20 也无法区分。** 而且因为 payoff 集中在 ~2.6% 的日子上，有效独立观测数大约是 10 个，Lo(2002) 的 SE 都是低估的。

更关键的推论：**这类 payoff 结构，2.2 年的窗口在设计上就没有检验能力。** 你的整个 post-publication evaluation 是一个 underpowered by construction 的实验。要在无条件 Sharpe 上区分 0.3 和 1.2，需要十年以上。

### 3.7 【中等】现金利息占了报告收益的一半

post 总 +17.19pp 里 cash interest +8.84pp。你在 amendment 文档里诚实地写了"剔除后 trading contribution 约 +8.35pp"，但 headline 表格里的 7.52% CAGR 没有拆。

真实的交易收益率是 **2.2 年 8.35pp ≈ 3.7%/年**，扣掉 3.3 节的 SEC fee 缺口后大约 **2%/年**。在 $100k 上是每年 $2,000。这是个必须直视的数字。

### 3.8 【中等】从未质疑过标的选择

整个项目默认交易 SPY。但这个策略需要 4x 杠杆、post 期 88% 的毛收益来自空头——**ES/MES 期货几乎在每个维度都更优**：

| | SPY | ES/MES |
|---|---|---|
| SEC Section 31 | 0.10 bp（均摊） | 无 |
| 借券费 | 25 bp p.a. | 无 |
| 杠杆融资 | SOFR + 100 bp | 隐含在基差里（通常更便宜） |
| 做空限制 | Reg SHO Rule 201 SSR（−10% 触发） | 无 |
| 半价差 | ~0.067 bp | ~0.18 bp |
| 交易时段 | RTH | 近 23 小时 |

单边交易成本大致打平（SPY 0.067+0.10+0.047 ≈ 0.21 bp；ES 0.18+0.03 ≈ 0.21 bp），但 SPY 输在借券和融资。而且 SSR 触发条件恰好是策略最赚钱的那种日子。

**这是个必须在实盘前定的决策，不是事后优化。**

### 3.9 【运营】东京时区

美股 RTH = JST 22:30–05:00（夏令时）/ 23:30–06:00（冬令时）。6.5 小时里每 30 分钟决策一次，**必须全自动无人值守执行**。这一项在当前模型里完全为零。

### 3.10 【方法论】post 窗口已经烧掉了，而且没有新窗口可用

你正确地拒绝叫它 OOS。但你已经在上面跑了 72-cell 矩阵、EOD 实验、完整归因——它现在是污染的。

问题是：**按 payoff 日 ~5% 的到达率，一个有意义的新冻结窗口需要 3–5 年。** 这条路实际上是走不通的。

## 四、实盘前策略层面必须落实的

### Tier 0：改变"你在做什么"的决策（先做，成本几乎为零）

**0.1 重新定义评估框架**

停止用 Sharpe / excess CAGR vs SPY。改成保险定价框架：

```
年化 carry     = 安静日 bleed × 安静日频率（当前约 −10~13 bp/day × 85%）
年化 payoff    = 大幅日 payoff × 大幅日到达率
净成本         = carry + payoff
比价对象       = 同等凸性的挂牌期权组合（rolling 5% OTM put spread / straddle）
```

决策变量变成：**"这个合成 straddle 比挂牌的便宜吗？"** 这是一个可判定的问题，而 "post Sharpe 是 0.3 还是 1.2" 不是。

**0.2 横截面广度检验——这是你现在能做的唯一真 OOS，也是最高杠杆的一步**

用完全相同的 spec，把信号跑到 15–20 个指数标的上：QQQ / IWM / ES / NQ / RTY / 日经 225 期货 / TOPIX / DAX / FTSE / KOSPI200 / HSI / 黄金 / 原油 / 美债期货。

判据：
- 如果机制在多数市场都有相同的 decile 形状（尾部赚、中间赔），这是**真实的市场结构效应**，post 期的疲软就确定是 regime 而非衰减
- 如果只有 SPY 有，那是过拟合，直接停

这同时解决了广度问题——你在另一个项目里已经接受了 fundamental law 的框架，这里完全适用：单标的方向性策略 breadth = 1，10–20 个指数的同一 alpha source 是完全不同的量级。而且**这些数据你基本都能拿到，工程复用度极高**。

**0.3 标的决策：SPY vs ES/MES**

在 0.2 的结果出来之前就可以定。我的判断是 futures 更优，但要你自己把日本税务口径核一遍（境外期货的 20.315% 申告分離 vs 雑所得的适用性，这个要问税理士，我不给结论）。

### Tier 1：可能翻转结论的成本项

**1.1 PIT SEC Section 31 费率序列**（如果决定继续做 SPY）
和你的 financing_rates_v1 同样规格：冻结、SHA、PIT。这一项单独就砍掉 43% 的 post net edge。

**1.2 State-dependent 滑点模型**
把滑点写成当时可观测量的函数，至少包含：滚动 5 分钟 realized range、当前 spread proxy、时段。**专门在 P&L 前 20 天上校准和压力测试**——因为那是唯一重要的样本。目标是回答：break-even 滑点 $0.011/share，在 2025-04-09 这种日子里实际滑点是多少？

**1.3 收盘执行**
你的 EOD 实验已经证明这是一阶影响。取 official auction print / TAQ，把 MOC 参与、imbalance、增量成本进状态机。

### Tier 2：把推断做对

**2.1 条件化推断，而不是无条件 Sharpe**

把估计对象拆成两个：

```
到达率模型：P(大幅日) —— 用长历史估计，波动聚集使它可预测
条件收益模型：E[payoff | 大幅日] —— 用全部历史的事件样本估计
```

这两个分开都比合起来稳定得多，而且能直接回答"post 到底是频率变了还是收益变了"。

**2.2 补上 block bootstrap / HAC / Deflated Sharpe**
不是为了做置信区间好看，而是因为**不做这个你会继续得出 3.1 那样的错误结论**。这不该"明确延期"，这该是最先做的。

### Tier 3：运营与风控（进实盘前的最后一关）

**3.1 东京无人值守执行**
美东 VPS、watchdog、心跳监控、断线自动平仓、每日 T+1 对账。ib_insync 的 reconnect 逻辑要压测。

**3.2 预先承诺的止损规则**
你必须提前接受这个数字：

```
2016–2017 两年     −23.25%（MDD −26.80%）
最差滚动 12 个月    −22.09%
15.6% 的 12 个月窗口为负
```

**在实盘前写下"什么情况下我停手"，并且这个阈值必须宽于 −23%**，否则你会在 2017 型 regime 里被震出去，然后错过 2018Q4（+29.3%）。这条规则必须冻结、签名、和 spec 一起入库。

**3.3 Paper trading 只测一件事**
不是测收益率。测的是：**在高波动日的 implementation shortfall**。安静日的执行误差无所谓，反正 P&L 也是零。跑 3–6 个月，专门捞出 SPY 日内动 > 1.5% 的那几天，比对预期成交价和实际成交价。
