# data-v1.0 研究起点决策

## 决策

data-v1.0 的正式研究区间固定为：

- `expected_start`: `2008-01-22`
- `expected_end`: `2026-07-09`

本决策于 2026-07-30 在冻结前作出。以后任何正式数据 manifest、回测
报告、图表和文字结论都必须显示精确起点 `2008-01-22`，不得把样本描述
为覆盖完整的 2008 日历年。

## 依据

原始文件 `SPY_1min_2008_202607_merged.parquet` 的首个观察 session 是
`2008-01-22`，并且该 session 有完整的 390 个 XNYS RTH bar。文件在
`2008-01-02` 至 `2008-01-18` 没有任何 session；使用
`expected_start=2008-01-01` 的边界探测曾正确识别 13 个缺失 XNYS
session 并拒绝发布。

选择 `2008-01-22` 的理由是：

1. 它是当前只读原始源中首个实际可得且完整的交易日；
2. 不需要虚构、插值或从其他 vendor 拼接 13 个未经同一审计流程验证的
   session；
3. 该选择在策略参数调整和 post-publication 结果评估之前冻结；
4. 起点不是根据 CAGR、Sharpe、回撤或任何策略结果挑选。

## 影响

- 研究声明从宽泛的“2008 年起”收窄为“2008-01-22 起”。
- `config/data_release_v1.yml` 使用
  `expected_start=2008-01-22`、`max_boundary_sessions_missing=0`。
- 边界完整性检查仍然保留：未来原始文件若缺少 2008-01-22 或
  2026-07-09 边界 session，正式运行仍必须失败。
- 不回填 2008-01-02 至 2008-01-18，也不把其视为零收益、休市或缺失
  分钟。
- 所有滚动特征从真实可得历史开始自然 warm up；不得向前借用数据。

## 非目标

本决策不证明 2008-01-22 之前的数据不存在，也不排除未来单独发布更长
历史版本。若未来获得并独立验证更早数据，必须创建新的 data release 和
新 evaluation spec；不得静默改写 data-v1.0。
