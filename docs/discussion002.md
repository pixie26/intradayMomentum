## 第一层：为什么"1.18 vs 0.30"这个比较本身没有信息

你现在的 headline 是这样一句话：

> pre-publication Sharpe 1.18，post-publication Sharpe 0.30 → 信号质量显著衰减

这句话在逻辑上等价于：

> 我抛了 10 次硬币得到 7 次正面，又抛了 10 次得到 4 次正面 → 硬币变了

**问题不在于 7 ≠ 4，而在于你没问"如果硬币根本没变，7 和 4 这种差异有多容易发生"。**

Sharpe 不是一个观测值，它是一个**估计量**。任何估计量都有抽样误差。你在 spec 里写"点估计；HAC 与 block bootstrap 明确延期"，等于你主动放弃了唯一能回答"这个差异是不是噪声"的工具，但你的结论恰恰完全依赖于这个问题的答案。

这就是我说"它恰恰是唯一的约束项"的意思：你所有其他工作（数据契约、状态机、成本拆分、72-cell 矩阵）都在提高**点估计的准确性**，但决策卡在**点估计的精度**上，而精度你一个数都没算。

## 第二层：block bootstrap 具体在做什么

普通 bootstrap：从你的 548 个日收益里，有放回地随机抽 548 个，重算一次 Sharpe。重复几千次，就得到"如果历史重演，Sharpe 会落在哪里"的分布。

**为什么要 block（分块）**：普通 bootstrap 假设每天独立。但金融收益不独立——波动率聚集（高波动的日子扎堆）、你的策略在连续几天的趋势里会连续赚钱。逐日打散会破坏这个结构，低估真实的不确定性。

所以改成：**不抽单日，抽连续 20 天的片段**。抽 28 个 20 天片段拼成 560 天，截到 548 天，重算 Sharpe。20 天大约是一个月，长到能保留波动率聚集，短到还能有足够多的独立片段。

我跑了 8000 次，结果：

| | 点估计 | bootstrap 中位数 | 5% | 95% | SD |
|---|---:|---:|---:|---:|---:|
| **PRE** (16年) | 1.20 | 1.20 | 0.85 | 1.56 | **0.21** |
| **POST** (2.2年) | 0.28 | 0.42 | −0.56 | 1.36 | **0.59** |

读法：**post 的 Sharpe 估计值，标准差是 0.59，比它自己的点估计 0.28 还大一倍多。**

顺带纠正我上一条里的一个错误：我当时说"Lo(2002) 的 SE 是低估的"，这个说法不准确。Lo 的 iid 公式给 0.68，bootstrap 给 0.59，bootstrap 反而更小（正偏度在公式里是有利项）。真正的问题不是数字大小，而是**形状**：post 的抽样分布不对称（点估计 0.28，中位数 0.42），所以"点估计 ± 1.65×SE"这种对称区间根本不适用。这也是为什么必须做 bootstrap 而不是套公式。

## 第三层：三个数字怎么读

**① 90% 区间 [−0.56, 1.36]**

意思是：如果真实 Sharpe 是这个区间里的任何一个值，观测到 0.28 都不奇怪。区间同时包含 0（策略无效）和 1.36（比 pre 期还好）。**这个区间的宽度告诉你：这 2.2 年数据没有排除掉任何一种可能性。**

**② P(Sharpe < 0) = 23.3%**

不要理解成"策略有 23% 概率是无效的"。正确读法：**即使真实 Sharpe 就是 0.28，重跑一次这 2.2 年，也有约四分之一的概率会看到一个负的 Sharpe。**这说明单次观测几乎不携带信息。

**③ 最关键的一个数，我上次没给你：直接检验 pre 和 post 的差**

```
Sharpe 差 (pre − post) 点估计 = 0.92
bootstrap 90% 区间       = [−0.21, +1.82]   ← 包含 0
P(pre ≤ post)            = 10.2%            ← 单边 p ≈ 0.10
```

**区间包含 0，p ≈ 0.10，在常规 5% 水平下不能拒绝"没有衰减"。**

所以正确的表述是：数据与"衰减了"相容，也与"没衰减、只是运气差"相容。你在 README 里写"质量显著衰减"，那个"显著"是没有依据的——而且"显著"在统计学里是有严格定义的术语，用错了会误导未来的你自己。

## 第四层：为什么说"有效独立观测数约 10 个"

这一层是最反直觉的，也是最重要的。

**核心直觉**：如果 100 个数里有 99 个是 0、1 个是 100，那你名义上有 100 个观测，但关于"这堆数的平均值"，你实际上只观测了 1 次。

标准的度量是 `N_eff = (Σx²)² / Σx⁴`（相当于平方收益的 Herfindahl 倒数）。正态分布下 `N_eff ≈ n/3`。我算了：

| | 名义 n | N_eff | 等价的"正态"样本长度 (3×N_eff) |
|---|---:|---:|---:|
| PRE | 4,064 天 (16年) | 312 | **937 天 ≈ 3.7 年** |
| POST | 548 天 (2.2年) | **18.9** | **57 天 ≈ 2.7 个月** |
| 参照：同长度正态样本 | 548 | 161 | 548 |

**你的 2.2 年 post 样本，在统计信息量上大约等于 57 个"正常"交易日 —— 不到三个月。**

而且注意 pre 期也没好到哪去：16 年历史只携带约 3.7 年正态样本的信息量。这解释了为什么你的 rolling 3年 Sharpe 会在 −0.20（2017）和 1.98（2024）之间乱跳。

**为什么会这样**，看这个：

```
post 期前 1 天 P&L  = post 总 P&L 的 106%   （这 1 天占样本 0.18%）
post 期前 3 天 P&L  = post 总 P&L 的 225%
post 期前 5 天 P&L  = post 总 P&L 的 320%
```

2025-10-10 一天贡献了超过整个 post 期的全部净利。剔掉它，post 就是亏的。

**所以"post Sharpe = 0.28"这个数字，本质上是由不到 10 个随机事件决定的。**你不是在观测 548 个独立样本，你是在观测大约 10 张彩票开奖结果。

这也解释了为什么 bootstrap 区间那么宽——重抽样时，那几天有时被抽中两次，有时一次都不被抽中，Sharpe 就在 −0.56 到 1.36 之间飘。

> 补充一个 bootstrap 自身的局限，它连回到我上一条的第 3.1 点：**bootstrap 只能重抽样出样本里出现过的事件。** post 期只观测到 9 个大幅日（占 1.64%），而 pre 期是 4.85%。如果真实到达率接近 pre，那 post 是欠采样的，bootstrap 会忠实地复制这个欠采样。所以这个区间是**以观测到的 regime 构成为条件的**，真实的不确定性只会更大。

## 第五层：为什么说"设计上就没有检验能力"

功效分析（power analysis）：**在你动手之前**，先问"如果差异真的存在，我这个实验有多大概率能发现它？"

要在 5% 显著性、80% 功效下检出 Sharpe 差 0.9（1.2 vs 0.3），需要估计量的标准差 < 0.36。我用你的实际收益分布 block-bootstrap 不同长度的窗口：

| 窗口长度 | SD(Sharpe 估计) | 够不够 |
|---|---:|---|
| 1 年 | 0.87 | 不够 |
| 2 年 | 0.61 | 不够 |
| 3 年 | 0.50 | 不够 |
| 5 年 | 0.38 | 不够 |
| **8 年** | **0.30** | **OK** |
| 12 年 | 0.25 | OK |

**你需要约 8 年才能在无条件 Sharpe 上区分 0.3 和 1.2。你有 2.2 年。**

"underpowered by construction"就是这个意思：这个实验的结论在你冻结 spec、写下 `evaluation_start: 2024-05-01` 的那一刻就已经注定是不确定的了。无论你把数据层做得多干净、状态机写得多正确、跑多少个 cell，都改变不了这一点。**这是设计问题，不是执行问题。**

顺便说：这也意味着你 roadmap 第 4 项"统计不确定性：在不改变 frozen v2 点估计的前提下增加 HAC 与 block bootstrap"的排序是反的。它不该排第 4，它该排第 0——因为它的输出会决定前三项还值不值得做。

## 那怎么办

功效 ∝ √(样本量 × 有效信息密度)。你有三条路，只有一条走得通：

**① 等更多时间** — 需要 6 年以上，且期间信号可能真的衰减。不可行。

**② 换一个 N_eff 高得多的估计量** — 这个可行，而且立刻能做。

不要估计"无条件 Sharpe"，改成估计两个东西：

```
到达率 λ = P(大幅日)         ← 用全部 18 年 + 波动率聚集估计，N_eff 很高
条件 payoff = E[收益 | 大幅日]  ← 用全历史约 200 个事件估计，比 post 的 9 个好 20 倍
```

无条件 Sharpe = 这两者的复合，但**分开估计各自的精度都远高于合起来**。而且这个分解直接回答你真正想问的问题：post 期到底是 λ 变了还是 payoff 变了。（我上一条已经给了初步答案：payoff 没变，λ 从 4.85% 掉到 1.64%。）

**③ 用广度换时间（横截面）** — 这是我上条说"如果只做一件事就做它"的统计学理由。

同一信号跑 15 个指数标的，有效样本量的提升是 `k / (1 + (k−1)ρ)`，ρ 是策略在各市场间日收益的平均相关性。大幅下跌日往往是全球同步的，所以 ρ 可能在 0.3–0.4：

```
k=15, ρ=0.40  →  有效倍数 ≈ 2.3x
k=15, ρ=0.25  →  有效倍数 ≈ 3.3x
```

不是 15 倍，但 2–3 倍意味着 2.2 年的横截面窗口 ≈ 5–7 年的单标的窗口。**加上 ② 的条件化估计量，才有可能在可接受的时间内把这个问题做成可判定的。**

---

**一句话总结**：你把巨大的精力投在消除偏差（bias）上，做得非常好；但你的决策卡在方差（variance）上，而方差你一个数都没算。而且以当前的设计，方差大到任何点估计的比较都是无意义的。
